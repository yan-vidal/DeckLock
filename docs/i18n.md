# Traduções

O aplicativo usa Fluent. Catálogos embutidos: `locales/en-US.ftl` e
`locales/pt-BR.ftl`. Selecione `--locale pt-BR` ou `locale = "pt-BR"` no TOML.
Sem seleção explícita, usa LC_ALL, LC_MESSAGES ou LANG, nessa ordem.

Para adicionar uma tradução sem recompilar, crie por exemplo
`minhas-traducoes/es-ES.ftl`:

```ftl
password = Contraseña
unlock = Desbloquear
preview-banner = Vista previa — la sesión no está bloqueada
date-format = %d/%m/%Y
```

```sh
scripts/cargo-local run -- --preview --locale es-ES --translations minhas-traducoes
```

As mensagens ausentes usam o catálogo embutido correspondente e, por último,
inglês. Um catálogo externo malformado falha com erro antes de abrir a tela.
`pt_BR.UTF-8` é normalizado para `pt-BR`; variantes de português/inglês usam os
catálogos pt-BR/en-US nesta primeira versão. `date-format` usa o formato de data
de GLib (`%d`, `%m`, `%Y`); `%A` e `%B` usam também as chaves
`weekday-1` a `weekday-7` e `month-1` a `month-12` do catálogo.
O relógio usa o fuso local do sistema.

Tradução da interface e layout de teclado são coisas distintas. O teclado físico
segue o compositor/GTK. O teclado virtual consulta o primeiro grupo do mapa GDK
na abertura e mantém a geometria do SVG original. `system_keyboard = false`
seleciona o mapa brasileiro embutido. Atualização dinâmica de grupos XKB e
layouts virtuais externos ficam pendentes. Os diagnósticos técnicos do terminal ainda
estão em inglês.
